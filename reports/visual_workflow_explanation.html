Multi-class classification with softmax objective. Class weights applied to handle imbalanced tiers (Stable 75%, Rising 15%, Shock 10%).

class_weight = balanced SHAP interpretation predict_proba → latent factors
Why classification first? Directly regressing cost is hard because the distribution is extreme. By first learning risk tiers, the model produces probability distributions (e.g., PROB_SHOCK=0.6) that encode rich information — even if two patients are both classified "Rising," their probability vectors differ and carry that nuance to Stage 2.

Stage 1.5A: Mental Health Trajectory

Logistic Regression cross_val_predict (5-fold) class_weight=balanced

Clinical rationale: Mental health decline often precedes cost escalation through reduced self-care, treatment non-adherence, and increased ER use.

Input Features

  • AGE_Y1, SEX
  • MNHLTH_RD1, RTHLTH_RD1 Baseline health
  • CHRONIC_COUNT Comorbidity burden
  • CNT_TOTAL_CONDITIONS
  • UTIL_ER_Y1, UTIL_OB_Y1
  • CNT_RX_Y1, POLYPHARMACY_FLAG
  • POVCAT_Y1, INSCOV_Y1
→

Output

  • PROB_MH_DECLINE P(mental health worsens Y1→Y2)
Target: MH_DECLINED = 1 if (MNHLTH_RD5 - MNHLTH_RD1) > 0 else 0 Model: LogisticRegression(class_weight='balanced') Output: cross_val_predict(method='predict_proba')[:, 1]

Stage 1.5B: Healthcare Engagement Score

Direct Calculation No ML model needed Range: [-1, +1]

Clinical rationale: Care-seeking behavior (proactive office visits vs. crisis-driven ER) strongly influences cost structure. This is directly observable from Y1 data.

Input Features

  • UTIL_OB_Y1 Office visits (positive signal)
  • UTIL_ER_Y1 ER visits (negative signal)
  • UTIL_IP_Y1 Inpatient stays (negative signal)
→

Output

  • ENGAGEMENT_SCORE +1=Proactive, -1=Crisis-mode
  • PROB_CRISIS_MODE sigmoid(−ENGAGEMENT × 3)
er_dep = ER / (ER + Office + 1) ip_int = normalize(IP_visits, cap=5) ob_eng = normalize(Office_visits, cap=P90) ENGAGEMENT_SCORE = normalize_to_[-1,1]( ob_eng - er_dep - 0.5 × ip_int )

Stage 1.5C: Undiagnosed Condition Risk ("Jumper" Detection)

RandomForestClassifier cross_val_predict (5-fold) class_weight='balanced'

Clinical rationale: "Hidden Risers" appear healthy in Y1 but have undiagnosed conditions that manifest in Y2. Ill-defined symptom codes (ICD R-codes) and frequent visits without clear diagnoses are warning signs.

Input Features

  • CNT_ILL_DEFINED Key: vague symptom codes
  • CNT_TOTAL_CONDITIONS
  • UTIL_OB_Y1, UTIL_ER_Y1
  • MNHLTH_RD1, RTHLTH_RD1
  • CHRONIC_COUNT, CNT_RX_Y1
  • AGE_Y1, SEX, COST_Y1_ADJ
→

Output

  • PROB_UNDIAGNOSED P(patient is a "Jumper")
Target: IS_JUMPER = 1 if (COST_Y1 < median) AND (COST_Y2 in top 10%) Model: RandomForestClassifier(n_estimators=200, class_weight='balanced') Output: cross_val_predict(method='predict_proba')[:, 1]

Stage 1.5D: Cost Escalation Pattern Score

Direct Calculation Weighted Composite Range: [0, 1]

Clinical rationale: Combines multiple clinical risk indicators into a single escalation score. Each component captures a different dimension of worsening health.

Input Components

  • CHRONIC_COUNT Comorbidity burden
  • CNT_ILL_DEFINED Diagnostic uncertainty
  • UTIL_IP_Y1 Hospitalization intensity
  • POLYPHARMACY_FLAG Medication complexity
→

Output

  • ESCALATION_SCORE Mean of 4 normalized components
ESCALATION_SCORE = ( norm(CHRONIC_COUNT) + norm(CNT_ILL_DEFINED) + norm(UTIL_IP_Y1) + POLYPHARMACY_FLAG ) / 4

Stage 1.5E: Treatment Discontinuation (Survival Analysis)

Cox Proportional Hazards lifelines library Kaplan-Meier validation

Clinical rationale: Medication discontinuation patterns (captured via time-to-event modeling) reflect patient adherence behavior and health trajectory — signals not available from cross-sectional features.

Input

  • TIME_TO_EVENT Months from first to last Rx fill
  • EVENT_DISCONTINUE 1 = stopped filling prescriptions
  • AGE, SEX, CHRONIC_COUNT
  • CNT_RX_Y1, MNHLTH_RD1, RTHLTH_RD1
  • POVCAT_Y1, INSCOV_Y1
→

Output

  • HAZARD_DISCONTINUE exp(β·X): relative hazard score
Cox Model: h(t|X) = h₀(t) × exp(β₁·AGE + β₂·CHRONIC + ... + βₚ·Xₚ) HAZARD_DISCONTINUE = exp(β·X) = 1.0 → baseline risk > 1.0 → higher discontinuation risk < 1.0 → lower discontinuation risk

Tweedie Regression (GLM with Log Link)

The Tweedie distribution (compound Poisson-Gamma) is specifically suited for healthcare cost data: it handles zero-inflation (many patients with near-zero costs), right skewness (few patients with extreme costs), and continuous non-negative values — all in a single model.

link = log power ∈ {1.2, 1.5, 1.8} alpha ∈ {0.01, 0.1, 1.0, 10.0} GridSearchCV (3-fold) StandardScaler preprocessing
E[Y|X] = exp(β₀ + β₁·X₁ + ... + β₃₀·X₃₀) Var[Y|X] = φ · E[Y|X]^p where p ∈ (1, 2) p = 1 → Poisson (count data) p = 2 → Gamma (positive continuous) 1 < p < 2 → Compound Poisson-Gamma (zero-inflated continuous) ← Our case
Data Split: Stratified by MEPS Panel (temporal) — 70% train / 20% validation / 10% test. This simulates real-world deployment where the model is trained on historical data and tested on future patients.

How Multi-Stage Improves Robustness

Compared to a single-stage model that directly predicts cost from raw features:

🧩

Complexity Decomposition

Each sub-model focuses on one clinical mechanism. Easier to learn, debug, and validate than forcing a single model to capture everything at once.

📊

Information Enrichment

Stage 2 sees processed signals (PROB_SHOCK=0.6) instead of raw features (ER_VISITS=3). Latent factors compress complex patterns into high-level features.

🔒

Leakage Prevention

Out-of-fold predictions (cross_val_predict) ensure latent factors don't contain training-set information. Temporal split validates on future data.

🔍

Clinical Interpretability

Each latent factor has clinical meaning. You can trace WHY a patient is predicted high-cost: mental health? engagement? undiagnosed risk?

⚖️

Imbalance Handling

Rare events (Shock ~10%, Jumpers ~2%) are modeled separately with balanced class weights, amplifying weak signals before they reach Stage 2.

🔄

Methodological Diversity

Different stages use different approaches (classification, direct calculation, survival analysis, regression) — each suited to its specific sub-problem.
